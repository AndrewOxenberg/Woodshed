# Woodshed

A guitar tab player and practice site with every feature Songsterr has, free
and paid, and no paywall: speed control, looping, transpose, solo and mute,
count-in, metronome, print, download, original-audio sync, an editor, and AI
transcription.

**State:** planning. No code yet. The plan is `woodshed-plan.md`, which holds
the full Songsterr feature inventory (§3), the constraints (§4), and the build
order (§7). Phase 1 is the practice player.

Tabs come from files you own (Guitar Pro, MusicXML, ASCII text), the built-in
editor, or AI transcription of your own audio. Woodshed does not copy
Songsterr's catalog (plan §4.1).
